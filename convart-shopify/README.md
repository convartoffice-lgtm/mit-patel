# ConvArt × Shopify checkout

Drop-in files that connect the convart.in Next.js site to a Shopify store. Copy the `src/`
folder over the site's `src/` folder; the paths match. Setup steps are in
[SHOPIFY_SETUP.md](SHOPIFY_SETUP.md).

Only the new and changed files live here. The rest of the website code isn't committed,
because this repository is public.
